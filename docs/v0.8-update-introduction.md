# OpenCareEyes 0.8 Beta 更新介绍：百变衣橱

OpenCareEyes 0.8 Beta 来了。

这一次，我们没有继续给设置页堆叠更多开关，而是把重点放回桌面上那只会陪你工作、学习和休息的小伙伴。全新的“百变衣橱”让宠物不只是换上一张静态贴图，而是能够以一整套造型完成待机、移动、点击、拖动、玩耍和休息等动作。

## 一套造型，也有完整的动作

0.8 Beta 新增了通用完整造型系统。衣橱现在包含三种明确模式：

- **自动搭配**：继续根据天气、节日和使用场景选择外观；
- **整套造型**：锁定一套包含服装、道具和动作的完整形象；
- **单件配饰**：继续使用帽子、围巾等独立配饰。

三种模式互不冲突，切换失败时会保留原来的造型，不会让伙伴突然变回默认外观。衣橱界面也改成了由宠物包清单驱动的响应式图库，支持宽屏双栏、窄屏单列和纯键盘操作。

## 首套造型：雪坡滑雪客

白鼬“鼬鼬”的第一套正式造型是“雪坡滑雪客”。

它穿着薄荷绿滑雪外套和浅蓝色护目镜，背着滑雪板背包，在细碎雪花中陪你穿过冬日雪坡。造型包含 29 帧正式透明资源，覆盖 10 类实际动作：

- 待机与蜷团休憩；
- 独立滑雪移动；
- 左、中、右光标视线；
- 鼠标点击回应；
- 拖动跟随与松手踉跄；
- 右键害羞；
- 雪地玩耍；
- 休息到点提示。

移动动作拥有独立步态，不会再出现“站着滑行”；光标靠近时只改变视线，不会让整只宠物突兀地左右镜像翻转。休息结束、跳过或暂停后，伙伴会回到当前造型的待机状态，不会残留睡眠动作。

## 陪伴更稳定，操作更顺手

除了衣橱，0.8 Beta 也集中修复了一批影响日常体验的问题：

- 安装升级时会先关闭仍驻留托盘的旧进程，减少文件被占用导致的安装失败；
- 伙伴快捷气泡的标题、说明、倒计时和空白区域均可拖动；
- 普通窗口最大化不再被误判为真正的全屏应用；
- 显示器热插拔、临时窗口避让或造型加载失败后，伙伴能够恢复到正确位置；
- 全屏、演示、锁屏和睡眠等情境下继续保持低打扰；
- 减少动画模式会停止自主移动和不必要的动画定时器。

休息提醒仍然使用同一个状态机。无论从伙伴气泡还是普通提醒卡操作，都可以选择“现在休息”“稍后 5/10/30 分钟”或“本次跳过”。

## 本地优先，没有额外负担

OpenCareEyes 0.8 Beta 继续保持无账号、无广告、无遥测。雪坡滑雪客的透明素材处理使用本地 NumPy 与 Pillow 工具，不依赖在线图像 API。

天气功能仍然默认关闭；只有用户主动开启并同意后才会请求天气数据。应用不会保存鼠标轨迹、窗口标题、完整程序路径或前台应用使用历史。

## 关于 Beta 版本

当前版本为 `0.8.0b2`，首先用于验证完整造型引擎和“雪坡滑雪客”的动作表现。后续造型将继续沿用同一套声明式宠物包规范，不改变休息、天气、屏幕舒适度和快捷工具等业务逻辑。

OpenCareEyes 的定位也保持不变：它是一款面向 Windows 学习与办公场景的桌面陪伴与观看舒适度助手，帮助你调节屏幕体验、形成休息习惯，同时让每天的电脑使用多一点轻松和陪伴。
