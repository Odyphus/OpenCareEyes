# 色温改由 Windows 夜间模式管理

v0.10.0b12 停止由 OpenCareEyes 写入显示器色彩曲线。屏幕页、首页、托盘和原色温快捷键提供“打开 Windows 夜间模式”的入口，强度、开启状态和定时在真实的 Windows 设置中调整。

## 用户能看到的变化

- 屏幕页移除软件自己的色温开关、Kelvin 滑块和数值，显示 Windows 夜间模式入口。
- 办公、阅读、夜间和游戏方案只调节软件遮罩的调暗强度，不改系统色温。
- 固定时间及日出日落自动方案只控制软件调暗；夜间模式的定时由 Windows 设置。
- 托盘夜间模式入口不再是可勾选的效果开关，原 Ctrl+Alt+N 快捷键打开系统设置。
- 关闭软件显示效果、暂停、恢复和退出软件都不修改 Windows 夜间模式。
- 移除只检测旧色温后端的“重新检测”按钮，避免无实际动作的入口；显示状态和关闭软件效果仍可使用。

旧设置里的色温偏好保留以便追溯，但生产运行入口会忽略它们；界面也不把旧温度或中性兼容值显示成 Windows 当前的实际色温。休息、专注、宠物及原版图标保持既有功能与资源。

## 调整依据

旧后端通过 `SetDeviceGammaRamp` 写入色彩曲线，并在校验失败时恢复原色彩。微软说明该接口具有全局覆盖、HDR及校色交互等限制，并建议蓝光调节使用 Windows 夜间模式。[微软接口说明](https://learn.microsoft.com/en-us/windows/win32/api/wingdi/nf-wingdi-setdevicegammaramp)。

本版本采用微软公开列出的 `ms-settings:nightlight` 入口。它打开 Windows 设置页面，不代表可以把系统设置界面嵌入软件或直接控制系统暖色强度。[微软设置入口文档](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)。本版本不通过私有注册表或外部小程序接管夜间模式参数。

## 实现与验证范围

生产入口使用无原生调色操作的 `SystemManagedColor`，不再创建 Gamma 工作线程。运行意图、显示事务与 UI 状态投影都抑制旧色温字段，自动方案和失败回退也遵守这一边界。

回归检查覆盖旧偏好启动、调暗方案、全局暂停与恢复、显示重检、托盘与快捷键、系统设置启动失败及调暗事务回退。测试拦截实际 Gamma 读写，验证这些路径不会调用旧接口。界面检查使用隔离设置和示例状态，不用频繁切换物理色温作为测试。

这能消除软件自己的调色路径，不能据此声称已定位或修复每一种显卡、屏幕或 Windows 夜间模式的硬件问题。已准备的 V0.10.0b11 软著材料仍是那个固定版本的材料，不随本次升级改写。
