# 手动调暗（v0.10.0b13）

屏幕调暗现在只保留手动开关和百分比滑块，默认关闭。办公、阅读、夜间、游戏按钮，以及固定时间和日出日落自动调暗均已移除。

## 使用

1. 打开“屏幕与休息 → 屏幕”。
2. 勾选“启用屏幕调暗”，再调整滑块。0% 表示不调暗。
3. 关闭开关即可撤下调暗遮罩。托盘与 `Ctrl+Alt+D` 也控制同一个开关。

关闭时调整滑块只保存强度，不会自行开启调暗。手动开关和强度会记住，下次启动沿用。系统时间、日出日落和应用例外不再改变调暗。用户主动选择“暂停全部效果”仍可临时停用，恢复后使用保存的手动设置。

色温继续由 Windows 夜间模式管理。“打开 Windows 夜间模式”只进入真实系统设置，不读取或写入色彩曲线。

## 升级

设置迁移到 schema v8 时，会关闭一次旧的调暗开关和自动日程，保留调暗强度及其他偏好。后续启动不会再次重置手动选择。旧“暂停到下一次自动切换”转为等待手动恢复；其他暂停方式保留。

“设置 → 免打扰”保留休息提醒和专注的情境规则。应用例外不再提供“暂停调暗”列，旧规则中的调暗数据仅保留作兼容数据，生产运行忽略它。首次设置简化为伙伴、休息节奏和启动方式三步。

## 验证范围

回归测试检查旧设置升级、开关与强度保存、关闭时调整、连续应用例外切换、旧日程与方案请求、键盘和托盘控制，并拦截旧 Gamma 读写。界面检查使用实际 Qt 组件、隔离偏好和模拟显示服务；不通过频繁改变用户的物理屏幕亮度进行验证。这些检查不等于已覆盖所有显示器和驱动组合。
