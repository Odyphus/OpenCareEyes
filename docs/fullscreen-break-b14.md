# 全屏时的休息处理（v0.10.0b14）

在“屏幕与休息 → 休息 → 提醒方式 → 全屏时”选择；托盘“更多操作 → 休息提醒 → 全屏时的休息”也提供相同的选择。

| 选择 | 全屏期间 | 退出全屏后 |
|---|---|---|
| 继续计时并提醒 | 正常计时，即使长时间不动鼠标也继续；到点按你选择的提醒方式提示 | 保留当前计时或待处理提醒 |
| 暂停计时 | 暂停休息计时和提醒，保留剩余时间；不会把这段时间当成已完成的自然休息 | 确认退出状态稳定后，接着剩余时间继续 |

名称只描述行为。软件不会根据“视频”“游戏”等名称替你选择模式；同一应用在不同使用场景下可以采用不同选择。设置会保存，退出软件后仍保留。

此选择独立于智能免打扰总开关和专注避让。锁屏、睡眠、用户手动暂停及已有应用例外仍有效。专注的全屏避让继续在“设置 → 免打扰”中调整，切换休息模式不会改变专注或手动调暗。

## 全屏时看得到提醒吗

“温和渐进提醒”在全屏情境下使用软件自己的右下角置顶卡片，即使倒计时选择了“桌面伙伴”、或者宠物不可见，也有独立的提醒入口。它不会抢走当前应用的键盘焦点。原有“到点立即全屏”和严格模式仍按其配置显示休息界面。

置顶是向窗口系统提出的显示要求，不保证覆盖所有全屏应用。[Qt 窗口标志说明](https://doc.qt.io/qt-6/qt.html#WindowType-enum)。独占全屏 Direct3D 和 Windows 演示状态与普通窗口全屏不同，系统通知也可能被勿扰规则隐藏。[微软全屏状态说明](https://learn.microsoft.com/en-us/windows/win32/api/shellapi/ne-shellapi-query_user_notification_state)、[Windows 通知和勿扰说明](https://support.microsoft.com/en-us/windows/experience/notifications-and-do-not-disturb-in-windows)。未能看到提示时，待处理的到点状态仍保留；退出全屏后可处理。

## 升级和验证

schema v9 将旧全屏暂停选择迁移为独立的休息模式，并保留专注避让、手动调暗强度、便签等其他设置。后续修改专注避让不会改变休息模式。

回归检查使用实际休息计时器和可控时钟，覆盖长时间无键鼠输入、到点提醒、全屏暂停和恢复、模式切换、锁屏和睡眠、严格模式、页面和托盘同步，以及宠物不可见时的全屏提示卡。Qt 界面检查与普通应用、独占全屏游戏的实际覆盖效果是不同验证范围；不把置顶标志或离屏截图当作所有全屏应用的显示保证。
