# v0.10.0b11 动作回滚与项目首页更新

原版白鼬和蓝围巾只保留 b10 的“摸摸头”与“玩一会儿”。待机、睡眠、移动、拖拽、放下、休息提示、懒腰、边缘探爪和注视按各自拥有的动作恢复 v0.9 发布标签中的原始图像、停留时间与循环设置；没有补帧、重采样或形变。v0.9 蓝围巾没有懒腰，相关菜单按原有规则显示为不可用。其他 12 套造型不变。

右键继续打开当前功能菜单，提供互动、重置位置和关闭伙伴；支持 Esc、菜单键和 Shift+F10。没有恢复旧右键动作，也不通过右键派发宠物动作事件。宠物包 schema 要求该动作字段存在，因此只保留一帧中性占位，取消 `right_click` 事件绑定。

恢复 v0.9 的原版与蓝围巾预览。原版包含 70 帧声明，蓝围巾 32 帧，其余 12 套各 29 帧。摸摸头与玩一会儿的全部 62 帧画面、时序和循环属性与 b10 相同；另有 38 帧取回 v0.9，2 帧是右键字段的中性占位。新版阅读、多方向注视、挥手和懒腰图集不再播放。

来源与回归基线保存在 [`action-policy-v010b11.json`](../artwork/companion/action-policy-v010b11.json)：恢复动作记录 v0.9 的声明和资源 SHA-256，保留动作记录 b10 每帧 RGBA SHA-256 与时序。正式构建直接打包已确认资源；历史动作构建脚本默认拒绝覆盖当前选择。

桌面、开始菜单和卸载入口继续采用 v0.9 原版蓝色眼睛 ICO，并使用 `OpenCareEyes-v09-9f222925.ico` 独立资源名。图标 SHA-256 为 `9f22292566eff202c0e8e4dccfff38ee8b46d01efb577628763e877a82d30cc1`。应用与托盘资源不重绘。

保留当前伙伴小屋、四项导航、按需展开的设置、低亮度休息场景和业务状态机。README 重新组织为下载、当前界面、功能、上手、边界和开发入口；旧版动作说明标记为历史材料。
